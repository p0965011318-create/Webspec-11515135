### 5.6 手沖工藝與粉水比計算機 (`#brew-guide`)

#### 左側：手沖儀式 4 步驟
1. **01 研磨與溫壺 (Grind & Rinse)**：中細研磨，90°C~92°C 熱水潤濕濾紙並溫熱下壺。
2. **02 悶蒸甦醒 (Bloom / 30-35s)**：以 2 倍粉重注水潤濕，排氣喚醒深層花果芳香。
3. **03 中心注水與均勻擾流 (Main Extraction)**：細水流穩定繞圈，溶出精華果酸與甘甜。
4. **04 尾段收水與品鑑 (Finish & Savor)**：自然滴濾至尾段移開濾杯，避免雜苦。

#### 右側：即時互動計算機
- **咖啡粉重量滑桿 (`#coffeeGramsRange`)**：
  - 最小值：`12g`，最大值：`30g`，預設值：`15g`，步進：`1g`。
  - 即時連動標籤：`#coffeeGramsVal`。
- **粉水比按鈕群 (`.ratio-btn`)**：
  - `1:14`：醇厚濃郁風格
  - `1:15`：清新均衡風格（預設啟用）
  - `1:16`：芳香輕盈風格
- **計算公式**：
  $$\text{總注水量 (Total Water)} = \text{咖啡粉克數} \times \text{比例}$$
  $$\text{悶蒸注水量 (Bloom Water)} = \text{咖啡粉克數} \times 2$$
  - 固定推薦水溫：`91 °C`
  - 預估萃取時間：`2 分 15 秒 ~ 2 分 35 秒`

## 6. 互動元件與 JavaScript 行為規格

### 6.1 購物車系統 (Cart Subsystem)
- **資料結構**：
  ```javascript
  // 陣列儲存購物車品項物件
  let cart = [
    { title: "巴拿馬 翡翠莊園 藝伎", price: 880, spec: "100g", qty: 1 }
  ];
  ```
- **核心操作函式**：
  - `addToCart(title, price, spec)`：加入商品，如存在則增加數量，更新 UI 並滑出抽屜。
  - `changeQty(index, delta)`：調整商品數量，若數量小於等於 0 則自陣列移除。
  - `removeCartItem(index)`：移除特定商品並顯示 Toast。
  - `openCart()` / `closeCart()`：切換抽屜 `.active` 類別及遮罩。
- **滿額免運進度條運算**：
  - 免運門檻：`const FREE_SHIPPING_THRESHOLD = 1000;`
  - 當金額未滿門檻時：顯示「還差 NT$ XXX」，進度條寬度按比例填滿，色彩為品牌綠。
  - 當金額達標時：文字切換為「🎉 恭喜！您已享有免運費優惠」，進度條寬度 100%，色彩切換為成功綠 (`#27ae60`)。
- **結帳處理 (`handleCheckout()`)**：
  - 若購物車為空，彈出提醒。
  - 若有品項，顯示確認對話框，清空購物車並關閉抽屜。
